visual rules · for new copy only

Bold + highlight treatment.

The brief above is plain so copy can be pasted cleanly. These rules tell the dev which words on the new site get a visual accent. Apply to new copy only — never to current copy.

  • R1

    One highlight per block. Never more.

    Pick the one or two words that carry the weight and mark them. If everything is highlighted, nothing is. A typical page has 5–8 highlights total, not 30.
  • R2

    Lime block background — for category / brand words.

    Use lime highlight on the defining noun of the category: growth operating system, Playbook, Compound Score, Dashboard, ALC Menu. Never on verbs. Never on filler words.
  • R3

    Orange block background — for numbers & proof-points.

    Use orange highlight on the number or the proof-claim: one score, 153-item, 20 April 2026, +87. Use sparingly — 1–2 per page maximum.
  • R4

    Inverted ink block — for short emphatic phrases only.

    Use ink highlight only on tabs, micro-labels, or a single emphatic phrase ("ONE SCORE."). Never on running prose. Never on the hero H1.
  • R5

    Weight contrast lives in Montserrat Black 900.

    The "alive and bold" feeling comes from Montserrat 900 at scale — not from more highlights. Keep H1/H2 at Montserrat 900, body at Inter 400/500. Don't add italic serifs. Don't add script fonts.
  • R6

    90° corners. Everywhere. No exceptions.

    No rounded corners on anything: hero video, hero imagery, tiles, cards, plan cards, credit bands, CTA buttons, inputs, avatars, social-share images. If a Webflow component ships with default radius, override to border-radius: 0. The hero video especially — radius 0 on the video element. Run a radius audit post-import.
  • R7

    Ink bars — not gradients.

    Top bar, CTA band, and footer use solid #1A1A1A with a 6px #DEE450 lime border underneath. No gradients, no shadows, no glow.
  • R8

    Full-width website. Hero + media go edge-to-edge.

    The site is full-width. The hero video sits edge-to-edge (no max-width container, no gutters). Hero-band imagery the same. The new statement band (section 14) is also full-bleed lime. Content rows stay in the 1120–1200px column, but all media bands go full-width. No rounded corners on any media, per R6.
